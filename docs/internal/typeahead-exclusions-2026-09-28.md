# Quick Actions typeahead exclusions, Piclaw 3.2.4

Installed Piclaw 3.2.4 opened Quick Actions from the timeline and kept it closed for composer and session-search typing in six browser/viewport cases. Ten additional excluded targets passed as synthetic DOM keyboard fixtures. The real CodeMirror and workspace-panel paths have not been accepted.

`make test-piclaw-typeahead-exclusions` runs `tests/ux/oracle/piclaw-typeahead-exclusions-probe.mjs` against the shipped Piclaw browser assets with isolated APIs. Chromium and WebKit phone, tablet and desktop cases each opened the palette with `q` on the timeline, closed it with Escape, and retained the composer draft after typing `z`. The shipped session picker accepted search input without opening Quick Actions. Synthetic input, textarea, select, contenteditable, composer, editor, workspace, dialog, popup and dock targets did not open the palette. Evidence: `test-results/ux-oracle/typeahead-exclusions/evidence.json`; final Makefile log: `/workspace/tmp/gi-typeahead-oracle-make.log`.

An earlier test sampled the open palette before its passive focus/effect cycle and sent Escape too soon; the popup remained visible. The corrected probe waits for the palette search field to own focus and a further animation frame. Failed attempts remain in `/workspace/tmp/gi-typeahead-oracle-live-attempt{3,4}.log` and `/workspace/tmp/gi-typeahead-oracle-final.log`.

Gi's existing `make test-ux-parity UX_PARITY_ARGS='tests/ux/quick-actions.spec.mjs --grep "exclusions preserve native inputs"'` passed 6/6 (`/workspace/tmp/gi-typeahead-native.log`). It covers native inputs and interactive controls plus synthetic editor/panel classes. `make check ux-parity-inventory` passed 144 functional tests with 11 skips and 214 support tests with 7,977 assertions (`/workspace/tmp/gi-typeahead-check.log`). The Classic `@ux-original-004` outline still requires real editor and workspace-panel interactions before mapping. This fixture does not test those loaded panes, physical keyboards or production deployments.
